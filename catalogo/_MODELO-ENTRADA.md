# [/COMANDO ou nome da skill]

| Campo | Valor |
|---|---|
| **Tipo** | código / skill / comando |
| **Origem** | fonte (ex.: 001 · nº 04) ou skill instalada |
| **Categoria** | planejamento, cálculo, documentação, obra, comercial… |
| **Função** | o que faz, em uma linha |
| **Quando usar** | situação em que gera resultado real |
| **Status** | não testado / testado em [data] / aprovado |

## Uso SEM contexto
Como a maioria usa. Prompt cru e o que costuma vir (genérico, sem número, sem norma).

## Uso COM contexto
Prompt com os dados que a IA precisa (obra, fase, norma, restrições, formato da saída).
Lista dos **insumos obrigatórios** que você deve fornecer.

## Exemplo
Entrada real + saída esperada (ou saída obtida num teste).

## Armadilhas
Onde erra, o que a IA inventa, o que não vale usar.

## Validação humana
O que precisa de responsável técnico / conferência em norma antes de usar.
