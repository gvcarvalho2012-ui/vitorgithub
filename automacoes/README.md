# Automações para iPhone — Performance e Memória Limpa

Coleção de automações prontas para deixar seu iPhone mais rápido e com memória sempre limpa.

## O que está incluído

| Arquivo | Tipo | Função |
|---|---|---|
| `shortcuts/limpar-memoria.md` | iOS Shortcuts | Limpa apps em segundo plano e libera RAM |
| `shortcuts/otimizar-bateria.md` | iOS Shortcuts | Reduz consumo e aumenta desempenho |
| `shortcuts/limpeza-semanal.md` | iOS Shortcuts | Rotina semanal automática de limpeza |
| `shortcuts/modo-performance.md` | iOS Shortcuts | Ativa configurações de máximo desempenho |
| `scriptable/monitor-memoria.js` | Scriptable | Widget com uso de memória em tempo real |
| `scriptable/limpeza-automatica.js` | Scriptable | Script de limpeza com relatório |

## Apps necessários

- **Atalhos** (iOS nativo, já vem instalado)
- **Scriptable** — [App Store](https://apps.apple.com/br/app/scriptable/id1405459188) (grátis)

## Como importar os Shortcuts

1. Abra o app **Atalhos**
2. Toque em **+** (canto superior direito)
3. Siga as instruções de cada arquivo `shortcuts/*.md`

## Como instalar os scripts Scriptable

1. Abra o app **Scriptable**
2. Toque em **+**
3. Cole o conteúdo do arquivo `.js` correspondente
4. Nomeie o script conforme indicado
5. Toque em **Concluído**
